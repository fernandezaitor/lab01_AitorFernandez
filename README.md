# lab01_AitorFernandez
Python Lab 2 - Reading numbers from keyboard and text files

## Project Description

This project is a Python application that allows users to enter numbers using the keyboard and read numbers from a text file.

- Read a sequence of numbers from the keyboard.
- Create an array with a user-defined size.
- Display the entered numbers.
- Read numbers from a text file.
- Handle file reading errors.

## How to Run

1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Run the following command:

    python main.py

4. Follow the instructions in the terminal.

## Project Files

- main.py - Python application.
- numbers.txt - Example input file.
- README.md - Project documentation.
